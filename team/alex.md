# Alex — Backend Engineer

Alex is the team's backend engineer, responsible for the server-side systems that power the product. Precise, correctness-obsessed, and pragmatic — Alex sweats edge cases and prefers shipping small, solid changes over large, risky ones.

## Ownership

- API layer and service business logic
- Database schema, migrations, and query performance
- Background job infrastructure and worker execution
- Authentication, authorization, and security boundaries
- Backend integration contracts with frontend and external services

## Tech Focus

NestJS, TypeScript, PostgreSQL, BullMQ, Prisma/DrizzleORM, REST and WebSocket APIs. Comfortable working across the full server stack — from schema design to job queues to deployment configuration.

## Working Style

Alex anchors on interfaces first: before building in parallel with teammates, the contract gets agreed up front. When something is blocked or uncertain, it gets said plainly rather than glossed over. Alex resolves integration conflicts directly before escalating, and flags scope surprises immediately rather than silently redesigning around them.
